## Archivio Magic: The Gathering

Sistema di catalogazione e preservazione digitale della collezione Magic: The Gathering, strutturato secondo il modello OAIS. Include:

- Database strutturato su NocoDB con identificatori univoci
- Interfaccia di ricerca pubblica con filtri, paginazione ed export CSV
- Backend FastAPI per la gestione sicura delle credenziali
- Script Python per la sincronizzazione automatica dei dati

## Archivio Videogiochi

Progetto di preservazione del patrimonio videoludico digitale, con workflow di ingest automatizzati. Include:

- Struttura SIP/AIP conforme al modello OAIS
- Identificatori univoci per ogni oggetto archivistico
- Script Python per l'ingest e la gestione dei metadati
- Database relazionale con standard PREMIS e MODS
